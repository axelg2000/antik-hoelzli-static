# antik-hoelzli-static

This repository contains the **static website** for Thomas Hoelzli, a designer and creator of unique handmade furniture. The purpose of this website is to showcase his work, present his collection, and share his creative universe with visitors.

👉 **Live Website:** [https://axelg2000.github.io/antik-hoelzli-static/](https://axelg2000.github.io/antik-hoelzli-static/)

## 📦 About This Repository

- This is a **static website** (HTML, CSS, JavaScript) – there is no backend functionality or database integration in this repo.
- It is intended for **presentation only**, focusing on Thomas Hoelzli’s furniture and design work.
- The layout and content are optimized for simplicity, speed, and clarity, reflecting the style and philosophy of the artist.

## 🪑 Related Project

A separate repository has been created for managing the **publication of furniture pieces**, using a model inspired by classified platforms like **Kleinanzeigen**.  
That project includes features for uploading, listing, and managing items dynamically.

## 🛠️ Technologies Used

- HTML5 & CSS3
- JavaScript
- Static hosting via [GitHub Pages](https://pages.github.com/)
